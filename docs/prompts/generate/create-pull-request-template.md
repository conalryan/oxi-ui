# 📄 Overview

Create a pull request template for a front-end mono-repo, multi-package, multi-version setup.

> **Goal:** Reusable pull request template to help engineers review code.

# 🧩 Requirements

- Front-end monorepo
- multiple libraries and applications
- version and publish independently

# 🎯 Scope

- Custom request template based on common templates and requirements of this repository.
